03 / Conflicts without the panic

See both sides. Choose the result.

When a merge, rebase or cherry-pick has conflicts, Gitastic shows your version, the other version and the live result together. Resolve it block by block or line by line — or edit the result directly.

  • Live preview of the resolved file
  • Accept blocks, groups of lines or single lines
  • Works with merge, rebase and cherry-pick conflicts

08 / Questions

Good to know.

Is Gitastic free?

Yes. Gitastic is open source under the Apache 2.0 license. You can download and use it for free.

Does Gitastic upload my code?

No. Gitastic runs locally on your machine. Your repositories are not uploaded to a Gitastic server, and there is no telemetry.

Can I use my existing repositories and remotes?

Yes. Gitastic works with your existing Git repositories, remotes and credentials. You can keep using the same workflow and hosting provider.

Does it work with GitHub and GitLab?

Yes, including self-hosted GitLab instances. You can clone repositories, browse pull requests or merge requests and open links in your browser.

Are the builds code-signed?

Not yet. macOS and Windows may show a warning the first time you open the app. Each release includes SHA-256 checksums so you can verify your download.

Which platforms are supported?

Gitastic is available for macOS (universal), Windows x64 and Linux x64.
